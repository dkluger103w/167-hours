# 167 Hours: Between Sessions

There are 167 hours between therapy sessions. This is for them.

This repository holds two things:

- **The Claude plugin** (`plugins/167-hours`), listed in `.claude-plugin/marketplace.json` so it can be added in Claude from this repository.
- **The website** (`site/`), published on Netlify at 167hours.app. The tester setup page is at `/start`.

The one rule: you need a therapist. 167 Hours supports therapy and never replaces it.

Not a crisis service. If you're in danger, call or text 988 or call 911.
